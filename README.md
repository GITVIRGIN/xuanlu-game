# 黑山酒馆 · R20 可玩分支

这是《黑山酒馆》当前 R20 浏览器版本的独立发布快照。该分支与仓库原有的
`main` / `xuanluxing` 内容隔离，不覆盖原项目历史。

## Windows 一键启动

下载或克隆本分支后，双击：

`一键打开黑山酒馆.cmd`

启动器会在本机寻找可用端口、启动静态服务并打开浏览器。请不要直接双击
`index.html`，因为浏览器会阻止 `file://` 下的 ES Module 加载。

## 当前内容

- 九名人物、六条路线，其中三名人物与三条路线需要在游戏中逐步解锁。
- 人物、路线与关键物件档案均可在世界卷宗查看；锁定内容提供非剧透线索。
- 一名主角与至多三名同行者的完整战斗、倒地、复起、压力博弈和终局战报。
- 27 节点正式单局流程，以及桌面和窄屏浏览器布局。
